# Sitio público de ROTGRE

Página de presentación de **Refaccionaria Autopartes y Equipo Industrial ROTGRE, S.A. de C.V.**,
publicada en <https://rotgre.com.mx>.

Es una sola página estática, sin dependencias ni proceso de construcción. La fuente de verdad vive
en el repositorio privado del proyecto, en `sitio/index.html`; aquí sólo se publica.

Cuando la plataforma de ventas entre en operación, el dominio apuntará al servidor de la tienda y
esta página dejará de estar en línea.

Diseño conforme a `design-system/rotgre-marketplace/MASTER.md`.
